# Typography Foundations

## Overview
Defined typographic hierarchy, font families, font sizes, line heights, and letter spacings configured in the Figma Design System.

## Typography Scale
| Style Name | Font Family | Weight / Style | Size | Line Height | Letter Spacing | Description |
| --- | --- | --- | --- | --- | --- | --- |
| Caption | Lato | Bold | 14px | Auto | 0% | - |
| Number | Lato | Bold | 50px | 100% | 0% | - |
| Heading/H1 | Lato | Bold | 22px | Auto | 0% | - |
| Heading/H2 | Lato | Bold | 20px | Auto | 0% | - |
| Heading/H3 | Lato | Bold | 18px | Auto | 0% | - |
| Body/Body large | Lato | SemiBold | 18px | 24px | 0% | - |
| Body/Body default bold | Lato | Bold | 16px | 22px | 0% | - |
| Body/Body default | Lato | SemiBold | 16px | 22px | 0% | - |
| Body/Body small | Lato | SemiBold | 14px | 18px | 0% | - |
