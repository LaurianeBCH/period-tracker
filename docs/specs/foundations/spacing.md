# Spacing Foundations

## Overview
Geometric grid increments and layout spacing primitives (margins, paddings, gaps) defined as Figma numerical variables.

## Spacing Scale
| Variable Name | Pixels (px) | Rem (base 16px) | Description |
| --- | --- | --- | --- |
| spacing/xs | 4px | 0.25rem | - |
| spacing/sm | 8px | 0.5rem | - |
| spacing/md | 12px | 0.75rem | - |
| spacing/lg | 16px | 1rem | - |
| spacing/xl | 24px | 1.5rem | - |
| spacing/2xl | 32px | 2rem | - |
| spacing/3xl | 64px | 4rem | - |


## CSS Custom Properties
```css
:root {
  --spacing-spacing-xs: 4px;
  --spacing-spacing-sm: 8px;
  --spacing-spacing-md: 12px;
  --spacing-spacing-lg: 16px;
  --spacing-spacing-xl: 24px;
  --spacing-spacing-2xl: 32px;
  --spacing-spacing-3xl: 64px;
}
```
